# 猎迹之眼设计方案

## 目标

为 MysticArtifacts 新增一个 Curios 饰品 `trail_sight`（中文名“猎迹之眼”）。玩家佩戴后，客户端渲染当前已加载实体最近 15 秒的移动轨迹，以左右脚印形式显示，并在实体离开范围、卸下饰品或切换世界时及时清理数据。

## 约束

- 目标版本为 Minecraft 1.20.1、Forge 47.4.6。
- 复用项目已经存在的 Curios 5.14.1+1.20.1 API，不增加第三方依赖。
- 只修改 `E:\Server_mod\MysticArtifacts` 主项目，不回退或重排工作树中已有的未提交改动。
- Java 包路径使用 `com.uniye.mysticartifacts`，不得出现 `example`。
- 轨迹是视觉效果，不持久化、不写入实体 NBT、不通过服务器同步。
- 专用服务器不得加载客户端渲染类。

## 方案

### 饰品

新增 `TrailSightItem extends Item implements ICurioItem`，注册到 `ModItems`。饰品支持从手上使用自动装备，提供 `isWearing(LivingEntity)` 查询方法。饰品本身不需要自定义 Curios 身体模型，使用普通物品模型和现有资源风格。

### 客户端采样

客户端 Forge tick 事件在玩家佩戴饰品时运行。采样对象为当前 `ClientLevel` 中已经同步并可见的所有 `Entity`，包括生物、玩家、掉落物和投射物。轨迹按实体 UUID 存储，避免实体数字 ID 复用导致旧轨迹串线。

每个实体对应一个有界队列，轨迹点包含：

- 世界坐标 `Vec3`；
- 移动方向或速度方向；
- 创建 tick；
- 用于左右脚印朝向的旋转角。

采样策略如下：

1. 每 2 tick 检查一次实体位置。
2. 水平位移为 0 时不新增点；只要水平位移不是 0 就记录。
3. 轨迹点年龄超过 300 tick（15 秒）立即删除。
4. 只保留距离玩家 48 格内的实体。
5. 全局最多保留 256 个实体轨迹；超出时保留距离玩家最近的实体。
6. 实体不再出现在客户端实体列表、跨维度或卸下饰品时清理对应数据。

这些限制将每个实体的记录上限控制在约 50 个点，并避免每帧遍历和无界内存增长。

### 脚印位置

每个轨迹点根据移动方向生成左右两个脚印：

- 左右偏移方向由移动方向的水平法线计算；
- 脚印沿移动方向旋转；
- 生物和玩家使用实体朝向作为后备方向；
- 掉落物和投射物使用速度方向；
- 没有有效方向的静止实体不生成新脚印；
- 轨迹点的 Y 坐标向下寻找脚下方的可渲染高度，避免脚印漂浮在空中。

### 世界渲染

客户端订阅 `RenderLevelStageEvent`，在实体渲染完成后的阶段绘制脚印。渲染器只读取轨迹缓存，不修改实体或世界状态。

脚印使用轻量半透明四边形/小型脚印纹理绘制：

- 新脚印透明度最高；
- 根据剩余寿命线性淡出；
- 启用深度测试，使方块可以遮挡脚印；
- 关闭深度写入，避免脚印污染后续世界深度；
- 每帧只渲染当前范围内且未过期的轨迹点。

非生物实体仍然使用相同的左右标记，但方向使用运动向量，因此可以观察投射物、掉落物等实体的行动路线。

### 配置

新增客户端配置项，默认值如下：

| 配置项 | 默认值 | 作用 |
| --- | ---: | --- |
| `trailSightRange` | 48 | 最大追踪距离 |
| `trailSightRetentionTicks` | 300 | 轨迹保留时间，默认 15 秒，范围 1–60 秒 |
| `trailSightSampleInterval` | 2 | 采样间隔 |
| `trailSightMinStep` | 0.0 | 最小移动记录距离，默认记录所有非零水平位移 |
| `trailSightMaxEntities` | 256 | 最大追踪实体数 |

配置注册为 Forge `CLIENT` 类型，避免把仅客户端的渲染参数同步到服务器。

## 数据流

```text
Curios 饰品槽
    ↓
客户端 tick 检查佩戴状态
    ↓
ClientLevel 实体列表
    ↓
按 UUID 更新有界轨迹队列
    ↓
RenderLevelStageEvent
    ↓
按年龄淡出的左右脚印
```

## 测试

先为不依赖 Minecraft 渲染类的轨迹队列和采样规则编写测试，覆盖：

- 15 秒后轨迹点过期；
- 小于最小位移时不新增点；
- 单个实体达到容量后丢弃最旧点；
- 全局实体达到上限后保留最近实体；
- 清理不存在实体和清空缓存；
- 卸下饰品后不再产生新轨迹。

随后执行资源契约检查、Java 编译和 Forge 构建，确认客户端类没有被专用服务器加载。

## 不在本次范围

- 不实现服务器保存或多人共享轨迹。
- 不给实体添加发光效果或修改实体渲染器。
- 不添加按实体类型筛选、颜色分类或 GUI 设置界面。
- 不改变项目现有饰品和工作树中的其他未提交功能。
